Cover Sheet Merger

Add your project's cover sheet to a document in Forma. Pick a cover file — a Word (.docx) cover is prepended to a Word document, an Excel (.xlsx) cover's COVER_SHEET tab is copied into a workbook as the first tab, a PDF (.pdf) cover's first page is added to the front of a PDF, and a PowerPoint (.pptx) cover's first slide is added as the first slide. The result is saved straight back to Forma as a new version.

How it works & known limits

Word (.docx): a Next Page section break is inserted between the cover and the document, so each keeps its own margins, headers, footers, page numbering and orientation. The document stays as the base; the cover's content is prepended and its images copied in. Cover-only custom styles fall back to the document's styles of the same name; the cover's own headers/footers and any tracked changes, comments or macros are not carried over.

Excel (.xlsx): the cover's COVER_SHEET tab is copied in as the first tab; the rest of the target workbook is left untouched. Cell formatting, merged cells, column widths and an embedded logo carry over. Charts, pivot tables or formulas referencing other tabs in the cover may not transfer. If the target already has a COVER_SHEET tab it is replaced.

PDF (.pdf): the cover PDF's first page is inserted at the front of the target PDF; all the target's existing pages are preserved in order.

PowerPoint (.pptx): the cover deck's first slide is added as the first slide of the target, carrying its own layout, master, theme and images so it keeps its design. The target's existing slides are preserved. Slide animations and embedded media beyond images may not transfer.

In all cases the result is uploaded as a new version of the target in Forma — the original is preserved in version history.
